# Scriptura estate lookup

This snapshot serves the combined lookup in the Scriptura Field Guide. It contains 280,117 catalogue records, with overlaps preserved. The manifest gives source ranges. Chunk files contain gzip-compressed JSON. Each entry records catalogue, source ID, title, alternate title, author, collection, status, linked witness count, recorded location, URL, source locator, original CSV row, and work ID. A graph alternate title is a candidate. Holdings alternate titles come from the original-title field.

Index files map normalized word prefixes to matching records. Original text, page scans and the full native source database are accessed separately through the source locators.
